# 未引用图片清理

此文档用于检查工作区图片扫描。以 `tests/manual/` 为本地工作区时，
`assets/示例图片.png` 被 `05-本地图片.md` 引用，不应列为候选。

## 浏览器内置存储中的清理与恢复

1. 导入本文档，打开它，将 `assets/示例图片.png` 拖入编辑器，等待图片保存。
2. 删除刚插入的图片引用，等待自动保存完成。
3. 在文件树根目录的“更多操作”中打开“清理未引用图片”。
4. 确认新生成的图片出现在候选清单中，取消勾选后按钮不可执行，重新勾选后移入回收站。
5. 在回收站恢复该图片，确认文件树重新显示；测试结束后只清理本次生成的副本。

本地目录模式仅检查候选清单，不要清理 `tests/manual/` 中的固定图片样例。
