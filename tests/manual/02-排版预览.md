# Markdown 排版样例

检查点：切换主题、密度和深浅预览，观察各级标题、段落间距、列表缩进、表格、代码与脚注是否清晰。复制后检查富文本结构。

## 二级标题：文字样式

普通正文包含 **粗体**、*斜体*、~~删除线~~、==高亮文字== 和 `行内代码`。中文与 English 混排，包含数字 12345、括号（示例）、引号“稿域”。

### 三级标题：链接与引用

[稿域项目](https://github.com/yscoder/AnyDraft) 是链接样例，预览检查无需访问外部页面。

> 一级引用中的正文。
>
> **引用中的重点**，以及第二段说明。
>
> > 二级引用用于检查嵌套缩进。

#### 四级标题：列表

- 第一项
- 第二项含有 **重点**
  - 子项甲
  - 子项乙

1. 起草内容
2. 检查预览
3. 复制与导出

- [x] 已完成的检查项
- [ ] 尚未完成的检查项

##### 五级标题：表格

| 项目 | 说明 | 数量 |

## 脚注

正文中的第一条说明[^preview]，以及另一条补充[^copy]。

[^preview]: 检查脚注编号、文字和段落间距。
[^copy]: 复制后的脚注也应能够阅读。
