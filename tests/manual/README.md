# UI 实测文档目录

此目录是可重复使用的手动测试工作区，不是自动化测试结果目录。

## 使用方法

1. 在仓库根目录运行 `npm run dev` 或 `npm run tauri:dev`。
2. 在应用中打开本目录 `tests/manual/`，检查文件树中的文档与子目录。
3. 按下表选择文档，执行文档内列出的检查点。
4. 编辑保存测试可在 `01-基础冒烟.md` 末尾输入一句话，等待保存后切换文档再打开，确认内容仍在，再删除自己输入的内容并等待保存。
5. 测试结束检查 Git 差异，仅恢复自己对样例的修改；清理自己生成的导入目录、备份和导出文件，保留测试前已有的修改。

浏览器内置存储模式可导入这些 Markdown 文档。单独导入 Markdown 不会自动携带图片；图片场景优先使用本地目录模式，或将 `assets/示例图片.png` 一并放入对应的存储路径。
